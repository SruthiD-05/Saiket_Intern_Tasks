## 🟣 Task Details

### 🔹 Task 1: Blog Post Layout

* Created a blog page using semantic HTML
* Included title, author, content sections, image, and link

---

### 🔹 Task 2: Product Card

* Designed a product card using HTML and CSS
* Added hover effects and proper styling

---

### 🔹 Task 3: Responsive Layout

* Built a webpage layout using CSS Grid
* Made it responsive using media queries

---

### 🔹 Task 4: Quiz Application

* Developed a quiz app using JavaScript
* Included multiple questions, validation, and score display

---

### 🔹 Task 5: To-Do List App

* Built a to-do list with add, delete, and complete features
* Used DOM manipulation for dynamic updates

---

### 🔹 Task 6: Landing Page (Headphones)

* Created a product landing page
* Added basic JavaScript interaction
